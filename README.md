# Sistema POS

Aplicación POS de una sola página para ventas, inventario, socios, arqueo de caja, respaldos y exportación de ventas.

## Uso

Abre `index.html` en un navegador moderno. Los datos se guardan localmente en el navegador; usa **Exportar respaldo JSON** desde Configuración antes de limpiar datos del navegador o cambiar de equipo.

## Acceso inicial

Usuario: `Administrador`  
Contraseña: `1234`

Modifica los usuarios y la información de la tienda desde Configuración al iniciar la operación.
